## App Store Connect fields

- **Privacy Policy URL** — `privacy-policy.html`
- **Support URL** — `support.html`
- **Marketing URL** — the site root. This is the one AdMob crawls to find
  `app-ads.txt`, and it renders as "Developer Website" on the App Store page.
  Support URL is a different field and is not crawled.

## app-ads.txt

One line, authorising Google to sell this app's inventory:

```
google.com, pub-6669089640170341, DIRECT, f08c47fec0942fa0
```

Not mandatory, but it protects against other apps spoofing this one. If it is
ever edited, the publisher ID must stay in it — a file that exists but omits the
ID stops Google buying ads on the app entirely, which is worse than having no
file at all.
